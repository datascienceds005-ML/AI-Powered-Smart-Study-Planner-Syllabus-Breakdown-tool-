   513→# 3. COCOMO Model Estimation (Team Size & Effort)
   514→
   515→## 3.1 Introduction to COCOMO
   516→
   517→COCOMO stands for Constructive Cost Model. It is a software cost estimation model developed by Barry W. Boehm.
   518→
   519→It is used to estimate:
   520→
   521→- Software development effort.
   522→- Development time.
   523→- Average team size.
   524→- Overall project cost.
   525→
   526→COCOMO estimates software development effort based on the size of the software, measured in KLOC (Thousands of Lines of Code).
   527→
   528→For this project, we will use the Basic COCOMO Model – Organic Mode.
   529→
   530→## 3.2 Why Organic Mode?
   531→
   532→The Organic Mode is suitable for small and relatively simple software projects developed by a small team with reasonable experience.
   533→
   534→Our Smart Study Planner project qualifies because:
   535→
   536→1. It is a relatively small academic application.
   537→2. It uses standard technologies such as Python and Streamlit.
   538→3. It has a modular architecture.
   539→4. It does not require complex hardware.
   540→5. It uses lightweight data processing and rule-based algorithms.
   541→6. Its development is manageable by a small student team.
   542→
   543→Therefore, Organic Mode is appropriate for this estimation.
   544→
   545→## 3.3 Basic COCOMO Formulas (Organic Mode)
   546→
   547→The following formulas are used:
   548→
   549→1\. Effort Estimation
   550→
   551→\\[ E=2.4\times(KLOC)^{1.05} \\]
   552→
   553→Where:
   554→
   555→- E = Development effort in Person-Months.
   556→- KLOC = Thousands of Source Lines of Code.
   557→
   558→2\. Development Time
   559→
   560→\\[ TDEV=2.5\times(E)^{0.38} \\]
   561→
   562→Where:
   563→
   564→- TDEV = Development time in months.
   565→- E = Estimated effort in Person-Months.
   566→
   567→3\. Average Team Size
   568→
   569→\\[ TeamSize=\frac{E}{TDEV} \\]
   570→
   571→Where:
   572→
   573→- E = Total development effort.
   574→- TDEV = Development duration.
   575→
   576→## 3.4 Project Size Estimation
   577→
   578→For this academic project, we assume the following source code sizes:
   579→
   580→| Project Size | Source Lines of Code | KLOC |
   581→| ------------ | -------------------- | ---- |
   582→| Small        | 2,000                | 2    |
